The work behind
the image.

A GPU-parallel rendering exercise turned into an interactive way to explore the complex plane.

View source on GitHub ↗
Project overview+

Each pixel maps to a point on the complex plane. The program repeatedly applies z = z2 + c and uses the number of iterations before escape to colour the image.

Explore the set+
  • WASDPan around the complex plane
  • + / -Zoom in and out
  • Z / XIncrease or decrease iteration depth
  • 1 – 3Choose a colour palette
  • RReset the view
GPU implementation+

The rendering kernel uses C++ AMP tiled parallel execution with 8 × 8 tiles. Each GPU thread computes a pixel independently; SFML displays the generated image, and the program reports render time.

Please note that older dependencies within this application, may affect running the project on current systems.
